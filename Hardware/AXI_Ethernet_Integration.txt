1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
The goal of this session was to integrate Ethernet connectivity into the existing
VeeRwolf RISC-V SoC targeting the Nexys A7 FPGA. The integration adds a third
AXI slave port to the PULP axi_xbar crossbar, routes it through a clock-domain
crossing bridge, and connects it to an axi_ethernet_0 MAC (Xilinx IP, MII mode)
via an RMII bridge (rmii_phy_if).

Key design decisions:
- Ethernet is a separate AXI slave port (NOT shared with the existing io_* bus)
- Address space: 0x80040000 – 0x80080000 (256 KB, covers 18-bit AXI4-Lite space)
- Clock domains: clk_core = 25 MHz (VeeRwolf), clk_eth = 100 MHz (MAC/AXI-Lite),
  clk_gtx = 125 MHz (GTX clock for axi_ethernet_0), eth_rmii_clk = 50 MHz (PHY)
- Data width adaptation: 64-bit AXI4 bus → 32-bit AXI4-Lite (w_data[31:0] for
  writes; eth_rdata_narrow zero-padded to 64 bits for reads)
- Clock domain crossing via axi_cdc_intf (already used in design for CPU→DRAM)
- MDIO bidirectional pin handled with Xilinx IOBUF primitive
- Active-high resets from rmii_phy_if inverted with `not` gates for AXI4-Lite

3. ethernet_top.sv  (Hardware.srcs/sources_1/new/ethernet_top.sv)
--------------------------------------------------------------------------------
New wrapper module instantiating axi_ethernet_0 and rmii_phy_if.

Port groups:
  - System:      s_axi_lite_clk, s_axi_lite_resetn, gtx_clk
  - AXI4-Lite:   s_axi_awaddr[17:0], s_axi_awvalid/ready, s_axi_wdata[31:0],
                 s_axi_wstrb[3:0], s_axi_wvalid/ready, s_axi_bresp[1:0],
                 s_axi_bvalid/ready, s_axi_araddr[17:0], s_axi_arvalid/ready,
                 s_axi_rdata[31:0], s_axi_rresp[1:0], s_axi_rvalid/ready
  - AXIS TX:     s_axis_txd_*, s_axis_txc_*
  - AXIS RX:     m_axis_rxd_*, m_axis_rxs_*
  - RMII PHY:    phy_rmii_ref_clk, phy_rmii_crs_dv, phy_rmii_rxd[1:0],
                 phy_rmii_rx_er, phy_rmii_txd[1:0], phy_rmii_tx_en
  - MDIO:        phy_mdio_i, phy_mdio_o, phy_mdio_t, phy_mdc
  - PHY reset:   phy_rst_n
  - Mode/IRQ:    mode_speed, mac_irq, interrupt

Internal MII wires connecting the two sub-modules:
  mii_rx_clk, mii_rx_dv, mii_rx_er, mii_rxd[3:0]
  mii_tx_clk, mii_tx_en, mii_tx_er, mii_txd[3:0]
  mii_rxrst (active-high), mii_txrst (active-high)
  mii_rxrstn, mii_txrstn (active-low, via `not` gates)

Sub-module instantiations:
  u_axi_ethernet_0  — axis_clk tied to s_axi_lite_clk;
                      AXI-Stream resets driven by mii_txrstn / mii_rxrstn
  u_rmii_phy_if     — rstn_async driven by s_axi_lite_resetn;
                      mac_mii_crs left unconnected

9. rvfpganexys.xdc  (Hardware.srcs/constrs_1/imports/src/rvfpganexys.xdc)
--------------------------------------------------------------------------------
Added at end of file (after CLKIN pin assignment):

  # Ethernet RMII reference clock (50 MHz from PHY)
  create_clock -add -name eth_rmii_clk -period 20.000 -waveform {0 10} \
               [get_ports { CLKIN }];
  set_clock_groups -asynchronous \
               -group [get_clocks sys_clk_pin] \
               -group [get_clocks eth_rmii_clk];

Notes:
  - eth_rmii_clk is the 50 MHz reference driven by the LAN8720 PHY on pin D5
  - sys_clk_pin (100 MHz board oscillator) and eth_rmii_clk are asynchronous;
    the set_clock_groups directive prevents false timing paths between them
  - clk_eth (100 MHz) and clk_gtx (125 MHz) are PLLE2 outputs derived from
    sys_clk_pin, so they are already related and need no additional grouping
